What yey does

It reads the values you allow from this SignalK server and answers questions about your boat — where it is, what the wind and depth are doing, what happened on passage. What it sends is set by a subscription plan you manage on the web, and it can never exceed what you consented to.

Price

$0.99 per month plus VAT for the base plan. Bring your own Claude API key (BYOK) and there are no token purchases at all — you pay Anthropic directly. Pricing
